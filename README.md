# واجهة شاشة تلفزيون بلايستيشن 5 الفائقة (PS5 TV UI Dashboard) 🎮📺

واجهة ويب متطورة لشاشات التلفزيون الذكية والكمبيوتر، تحاكي نظام تشغيل **سوني 5 (Sony PlayStation 5)** بدقة متناهية، ومصممة بأعلى معايير الخفة والسرعة الفائقة وسلاسة التحكم بالريموت والماوس الهوائي (Air Mouse) وأيدي التحكم (DualSense / Gamepad).

جاهزة تماماً للرفع والتشغيل المباشر على **GitHub Pages** بدون أي برامج مساعدة أو خطوات بناء (Zero Build / Zero Dependencies).

---

## 🌟 أبرز المميزات

- ⚡ **تحكم فائق الخفة والسرعة (Ultra-Fast 60/120 FPS):**
  - استجابة لحظية 0ms بفضل التسريع العتادي الكامل (GPU Hardware Acceleration) عبر `transform: translate3d` و `will-change`.
  - انعدام التقطيع واللاغ حتى على شاشات التلفزيون ذات المعالجات المتوسطة.
- 🎯 **دعم ريموت التحكم والماوس الهوائي (Air Mouse Engine):**
  - مؤشر ليزري متوهج مخصص للريموت الهوائي يتحرك بسلاسة مطلقة.
  - 3 خيارات لحساسية سرعة الماوس: **عادي (1.0x)**، **سريع وسلس (1.6x)**، و **فائق السرعة وخفيف (2.4x)**.
  - ميزة الجذب المغناطيسي (Magnetic Card Attraction) التي تجذب المؤشر تلقائياً لبطاقات الألعاب بدقة وراحة لليد.
  - التبديل الذكي التلقائي بين الماوس وأزرار الأسهم D-Pad مع إخفاء المؤشر عند عدم استخدامه.
- 🎮 **تطابق بنسبة 100% مع واجهة PlayStation 5 الرسمية:**
  - **الشريط العلوي:** تبويبي «ألعاب» و «وسائط» مع شريط التوهج الأبيض النشط، أيقونات البحث، الإعدادات، الملف الشخصي مع النقطة الخضراء ومستوى الجوائز 🏆 428، والساعة الرقمية الحية.
  - **الشريط الأفقي للألعاب (Ribbon Carousel):** متجر بلايستيشن، Spider-Man 2، God of War Ragnarök، EA SPORTS FC 25، Black Myth: Wukong، ASTRO BOT، GTA V، Ghost of Tsushima.
  - **تبويب الوسائط (Media):** YouTube، Netflix، Shahid VIP، Twitch، Spotify.
  - **مرحلة تفاصيل اللعبة (Game Stage):** شعار اللعبة، حالة اللعب، زر «تشغيل اللعبة ▶» المتوهج، زر الخيارات، شريط تقدم الكؤوس والجوائز، وبطاقات الأنشطة السريعة (Activity Cards).
  - **مركز التحكم السفلي (PS5 Control Center Dock):** يفتح بالضغط على زر PS أو السحب لأسفل، ويضم: الرئيسية، المبدل، الإشعارات، قاعدة الألعاب، الموسيقى، الصوت، الإعدادات، ووضع السكون للطاقة.
  - **مؤثرات صوتية أصلية لبلايستيشن 5:** أصوات التنقل (Tick)، التأكيد (Confirm Chime)، الرجوع (Back Whoosh)، وفتح الألعاب مُولدة فورياً عبر محرك `Web Audio API` بدون الحاجة لتحميل ملفات صوتية ثقيلة (0ms Network Latency).
  - **شاشة بدء اللعبة (Game Launcher):** شاشة بدء تشغيل سينمائية لأي لعبة مع شريط تحميل واقعي ومحاكاة التشغيل.
  - **دعم كامل للغة العربية والإنجليزية:** تبديل فوري للغة وتنسيق الواجهة بضغطة زر.
  - **وضع ملء الشاشة (TV Fullscreen):** للانغماس الكامل على شاشات التلفزيون بدقة 4K و 1080p.

## 🕹️ دليل التحكم واختصارات الريموت

| الوظيفة | ريموت التلفزيون / لوحة المفاتيح | يد التحكم (DualSense / Gamepad) |
| :--- | :--- | :--- |
| **التنقل بين الألعاب والبطاقات** | أزرار الأسهم (⬆ ⬇ ⬅ ➡) أو مفاتيح WASD | D-Pad أو عصا التحكم اليسرى (Analog Stick) |
| **تشغيل اللعبة / اختيار العنصر** | زر **Enter** / **OK** / **Space** | زر **✕** (Cross / A) |
| **الرجوع للخلف / إغلاق النوافذ** | زر **Back** / **Return** / **Esc** / **Backspace** | زر **◯** (Circle / B) |
| **فتح مركز التحكم (Control Center)** | زر **Home** / **Menu** / مفتاح **P** أو **M** | زر **PS** (PlayStation Logo Button) |
| **التبديل بين الألعاب والوسائط** | من خلال الشريط العلوي بالماوس أو الأسهم | زري **L1** و **R1** |
| **الماوس الهوائي (Air Mouse)** | تحريك الريموت بالإشارة أو الماوس العادي | عصا التحكم التناظرية |

## 🚀 طريقة التشغيل والنشر على GitHub

### 1. النشر المباشر عبر GitHub Pages (مجاني برابط مباشر)
1. افتح مستودعك على GitHub: `https://github.com/omaralatwi999/abyk-tswy-kwd-wajht-shasht-tlfzywn`.
2. ادخل إلى **Settings** (الإعدادات) في المستودع.
3. من القائمة الجانبية، اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - اضبط الـ **Source** على `Deploy from a branch`.
   - اختر الفرع `main` والمجلد `/ (root)`.
   - اضغط **Save**.
5. خلال دقيقة سيظهر لك الرابط المباشر للواجهة، ويمكنك فتحه مباشرة من متصفح الشاشة الذكية!

### 2. التشغيل المحلي (Offline / Local)
- حمّل الملفات وافتح ملف `index.html` في أي متصفح (Chrome, Edge, Samsung Internet, LG WebOS Browser).
- اضغط زر **F11** لتفعيل ملء الشاشة، واستمتع بتجربة بلايستيشن 5 كاملة على شاشتك!
